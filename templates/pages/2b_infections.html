How these figures were calculated

Country infection rate
Cases are divided by the country's national population and multiplied by 100,000: cases ÷ population × 100,000.
Economic status
Countries are grouped using the economic classification stored in the database. Countries without a classification are retained as Not classified rather than silently removed.
Summary infection rate
The summary combines the selected countries by dividing their total reported cases by their combined population and multiplying by 100,000. This produces a population-weighted rate for the selected economic group.
Data processing
SQL performs the filtering, aggregation, rate calculation and sorting. Python validates user selections and prepares values for display, while HTML presents the resulting information.
Zero values
A reported zero is displayed as zero rather than being treated as missing. A reported zero; review data label marks values identified by the dataset's consistency check as potentially suspicious. This is a data-quality warning, not proof that no infections occurred.
