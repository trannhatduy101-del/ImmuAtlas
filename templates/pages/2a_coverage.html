{# ---- Method note ---- #}

How these figures were calculated

Coverage
The figure each country reported to WHO. Its denominator is the birth cohort that country targeted, not its total population: coverage = doses ÷ target cohort × 100.
Doses per 100 people
Doses ÷ national population × 100. This is not a coverage rate. It is shown so a population-based reading is available, labelled for what it is.
Regional average
Each national figure weighted by the birth cohort it applies to, summed across the region. The unweighted mean is printed beside it so the difference is visible.
Threshold
{% if threshold and threshold.threshold_pct is not none %} {{ fmt_pct(threshold.threshold_pct, 0) }} for {{ threshold.disease_name }}. {{ threshold.threshold_note }} Source: {{ threshold.threshold_source }} {% if threshold.threshold_url %} Read it {% endif %} {% else %} Select a single antigen to see the threshold that applies to it. {% endif %}
Met target
Counts the countries in a region whose reported coverage reached the threshold, out of the countries that region has in this selection. Countries are counted once each, not once per row — so with no year chosen, a country counts as having met the target if it did so in at least one year of the selection. The column only appears once a single antigen is chosen, because the threshold belongs to the disease.
Exclusions
Records with no coverage figure are excluded from every average rather than counted as zero. They are stored as blanks, not as nulls, so an ordinary average would silently treat them as zero and pull every regional figure down. Coverage above 100% is kept, not capped: doses given outside the target cohort are real. Countries with no economic classification and territories with no country entry are shown as “Not classified” and “unmatched” rather than dropped.
