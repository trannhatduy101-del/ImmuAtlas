{# ---- Method note ---- #}

How these figures were calculated

Percentage of target
A country’s doses divided by the number of children it aimed to reach: doses ÷ target group × 100. Countries report this figure to WHO.
Doses per 100 people
Doses divided by the whole population rather than the target group: doses ÷ population × 100. It answers a different question, so the two figures differ.
Regional average
Each country counts towards its region in proportion to the children it aimed to reach, so a large country carries more weight.
Threshold
{{ fmt_pct(threshold_pct, 0) }} for every vaccine on this page. WHO sets its own figure for each disease: 95% for measles, 90% for diphtheria-tetanus-pertussis and 80% for rubella. {% if threshold and threshold.threshold_pct is not none %} For {{ threshold.disease_name }} it is {{ fmt_pct(threshold.threshold_pct, 0) }}. {{ threshold.threshold_note }} Source: {{ threshold.threshold_source }} {% if threshold.threshold_url %} Read it {% endif %} {% endif %}
Met target
Each country counts once. With no year chosen, a country counts if it met the target in any year of the selection.
Exclusions
Countries that reported no figure are left out of the averages rather than counted as zero. Figures above 100% are shown as reported, since a country can deliver more doses than it has children to reach. Countries with no region or income group are still listed, and labelled.
